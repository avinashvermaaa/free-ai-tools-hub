# Git Commit Guidelines

Always use the following prefixes for git commit messages:
- `feat :- ` for new features
- `fix :- ` for bug fixes
- `chore :- ` for build tasks, dependencies, etc.
- `security :- ` for security improvements
- `style :- ` for UI styling changes and styling updates
- `revert :- ` for reverting previous commits
- `perf :- ` for performance improvements
- `docs :- ` for documentation updates
- `test :- ` for adding or modifying tests
- `refactor :- ` for refactoring code changes without changes to behavior
